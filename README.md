# 台风实况网站

一个面向公众的台风实况信息网站，用来快速回答五个核心问题：

1. 台风叫什么？
2. 台风现在在哪里？
3. 台风往哪里走？
4. 台风当前是什么等级？
5. 当前风力有多大？

网站强调信息清晰、移动端易读、数据来源可追溯，以及“最后一次更新时间”始终可见。

## 当前阶段

已完成静态网页演示版，包含实况数据面板、路径示意图、预警信息和演示数据声明。完整的产品与开发计划见 [docs/PLAN.md](docs/PLAN.md)。

## 本地预览

项目不依赖第三方前端库。在仓库根目录启动任意静态文件服务器，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。也可以直接打开 `index.html`。

> 页面中的台风、路径、风力和预警均为虚构演示数据，不可用于真实航行、避险或防灾判断。

## 建议技术方向

- Next.js + TypeScript
- Tailwind CSS
- MapLibre GL JS
- 服务端数据适配、缓存与限流
- 先以模拟数据完成界面，再接入经确认的官方或授权数据源
