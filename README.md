# 台风实况网站

一个面向公众的台风实况信息网站，用来快速回答五个核心问题：

1. 台风叫什么？
2. 台风现在在哪里？
3. 台风往哪里走？
4. 台风当前是什么等级？
5. 当前风力有多大？

网站强调信息清晰、移动端易读、数据来源可追溯，以及“最后一次更新时间”始终可见。

## 当前阶段

项目目前处于方案设计阶段。完整的产品与开发计划见 [docs/PLAN.md](docs/PLAN.md)。

## 建议技术方向

- Next.js + TypeScript
- Tailwind CSS
- MapLibre GL JS
- 服务端数据适配、缓存与限流
- 先以模拟数据完成界面，再接入经确认的官方或授权数据源
